## Proposed (need Davit)

1. **Admin typeface** — Product app is locked to **Plus Jakarta Sans**. Nar mentioned Inter / Inter Tight for dense tables.  
   - *Proposed:* keep **Plus Jakarta Sans** everywhere (one family, brand continuity).  
   - *Alt:* Inter for admin tables/body only; PJS for lockup + marketing surfaces.  
   - Mock uses **PJS**.

2. **Sidebar colour** — *Proposed:* **Navy `#1B2747`** sidebar (ops weight, matches app chrome).  
   - *Alt:* white sidebar + coral active (lighter “paper” admin).

3. **Environment badge** — *Proposed:* show `Staging` / `Prod` in top bar always.  
   - *Alt:* Prod hidden; Staging + Preview only.

4. **Countries reorder** — *Proposed:* drag-handle on Available list only; Coming Soon separate list (no cross-list drag in v1). Live toggle per row.

5. **Destructive colour** — *Proposed:* quiet danger `#B42318` / `#FEF3F2` — **never** cloth red `#8B1E2D` (covers only). Confirm.

6. **Roles matrix** — *Proposed stub:* Admin · Editor · Support.  
   - Admin: all. Editor: countries/places/ads/rules (no user delete, no roles). Support: moderation inbox + user read/adjust coins with audit.  
   - Need: who can mint coins / force-collect stamps?

7. **Ads surface** — *Proposed:* in-app promo slots only (Countries banner, Trade strip, Me card). No third-party ad network in v1 admin.

8. **Trade & coins numbers** — Product copy: chapter complete **+50** coins, country complete **+200**.  
   - *Proposed:* admin can edit these globally; per-country overrides later. Confirm defaults locked.

9. **Moderation scope** — *Proposed stub:* user↔user Trade disputes + Support tickets from app. Photo/UGC moderation only if user uploads land (not in current app-preview).

10. **Desktop breakpoints** — *Proposed:* admin desktop-only ≥1280; no mobile admin v1.
